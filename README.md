# 比特币定投收益分析网站

这是一个静态网站，用于展示2025年比特币定投收益分析数据。

## 项目结构

- `btc-price2025.csv` - 原始比特币价格数据（2025年）
- `index.html` - 网站主页面
- `style.css` - 样式文件，包含现代化的设计和动画
- `data.js` - 数据处理和图表渲染脚本
- `investment_data.json` - 计算好的投资数据
- `calculate_investment.py` - Python脚本，用于从CSV计算投资数据
- `README.md` - 项目说明文档

## 使用方法

### 查看网站
直接在浏览器中打开 `index.html` 文件即可查看。

### 更新数据
如果需要重新计算投资数据：
```bash
python3 calculate_investment.py
```

这将更新 `investment_data.json` 文件。

## 数据计算说明

- **投资周期**：2025年1月1日 - 11月15日
- **每日投入**：$100 USD
- **投资频率**：每月每天投入（1号、2号、3号...直到当月最后一天）
- **总购买次数**：28 次
- **总投入金额**：$2,800 USD
- **卖出日期**：2025年11月15日
- **卖出价格**：$96,971 USD/BTC

## 网站功能

- **概览卡片** - 显示关键投资指标
- **详情展示** - 投资详情和市场数据
- **互动图表** - 使用 Chart.js 展示：
  - 资产变化趋势（累计投入 vs 资产价值）
  - 比特币价格走势
  - 各月购买分布与成本均价
- **交易明细表** - 所有购买记录的详细信息
- **响应式设计** - 支持桌面和移动设备
