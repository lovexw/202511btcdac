# 比特币定投收益分析网站

一个专业的比特币DCA（定投）收益分析静态网站，采用比特币官方配色（橙色主题），提供直观、大气的数据展示和交互体验。

## ✨ 主要特性

### 🎨 设计特点
- **比特币橙色主题** - 采用 #F7931A 官方配色
- **大气现代设计** - 采用大字号、高对比度展示关键数据
- **玻璃态UI** - 毛玻璃效果设计，深色背景
- **流畅动画** - 渐进式加载动画和过渡效果
- **完全响应式** - 完美支持桌面、平板和手机设备

### 📊 功能特性
- **概览卡片** - 四大关键指标一览无余
  - 总投入金额
  - 持仓比特币数量
  - 当前资产价值
  - 收益/亏损状态

- **详细指标** - 三个详情卡片展示
  - 投资概览（周期、次数、天数）
  - 市场数据（均价、卖出价、价格变化、波动率）
  - 收益指标（收益金额、收益率、最高最低购入价）

- **互动图表** - 使用Chart.js 3.x渲染
  - **资产增长曲线** - 累计投入 vs 资产价值对比
  - **BTC价格走势** - 完整价格历史曲线
  - **月度购买分析** - 每月购买次数与成本均价对照

- **可排序数据表**
  - 按购买日期排序（默认）
  - 按比特币价格排序
  - 按资产价值排序
  - 支持升序/降序切换
  - 详细显示：序号、日期、价格、投入金额、购入数量、累计投入、累计持仓、资产价值

## 🚀 使用方法

### 在浏览器中查看
```bash
# 直接打开index.html
open index.html

# 或使用本地服务器
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

### 更新投资数据
```bash
python3 calculate_investment.py
```

此命令会重新读取 `btc-price2025.csv` 并更新 `investment_data.json`。

## 🎯 计算规则

**投资方式** - DCA（定投）
- 投资周期：2025年1月1日 - 11月15日
- 购买频率：每个月每天都买
- 购买规则：1号、2号、3号...直到当月最后一天
  - 例如2月有28天，则购买28次
  - 例如3月有31天，则购买31次
  - 11月只购买到15日，共15次
- 单次投入：$100 USD
- 卖出日期：2025年11月15日
